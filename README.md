# ZalogHub — список задач

Приложение для создания и управления задачами. Список сохраняется в `localStorage` браузера.

## Запуск

```bash
pnpm install
pnpm dev
```

Для production-сборки выполните `pnpm build`.

## Структура

- `src/components/` — приложение, поле ввода, фильтры и компоненты списка.
- `src/hooks/` — управление задачами и синхронизация с `localStorage`.
- `src/types/` — типы задачи и фильтра.
- `src/utils/` — создание идентификаторов и форматирование счетчика.
- `src/styles/` — глобальные стили, переменные и стили приложения.
